# 考研词根记忆卡片

一个单文件、离线可用的网页版单词记忆工具：5258 个考研词 + 音标 + 释义 + 2017—2026 考研英语（一）真题频率与例句讲解 + 词根/主题/形近老师口诀，带自测、间隔复习、学习统计、进度导出/导入、学习网站收藏，以及每日一首古诗词的英文翻译弹窗。

手机浏览器直接打开即可，无需安装、无需联网（打开后全程离线）。

## 文件结构

```text
index.html            成品网页（GitHub Pages 直接部署这个）
src/
  build_app.py        生成脚本：运行后重新生成 index.html
  groups.json         词库与分组数据
  teacher_rhymes.py   各组老师口吻口诀
```

## 发布到 GitHub Pages

1. 新建仓库，把 `index.html` 传到仓库根目录。
2. Settings → Pages → Source 选 main 分支 / root → Save。
3. 得到网址 `https://你的用户名.github.io/仓库名/`。

## 如何更新

- **改文案/口诀/逻辑**：编辑 `src/` 下的文件，然后运行：

  ```bash
  python3 src/build_app.py
  ```

  会重新生成根目录的 `index.html`，把新文件上传覆盖仓库即可。
- **改词库数据**：编辑 `src/groups.json`（单词、释义、真题例句、分组都在里面）。
- 更省事：把要改的内容告诉我，我来改源码并生成新 `index.html`，你负责上传更新。

## 进度说明

学习进度、收藏的网站、收录的诗词都存在浏览器本地。换设备时用「统计」页的「导出进度 / 导入进度」搬运即可；不换域名、不清浏览器缓存就不会丢。

> 说明：`groups.json` 是从「无痛单词」App 本机词库导出的快照，已包含生成网页所需的全部字段，不需要联网或依赖 App。
