# 考研统筹舱 · future

「未来的我实现梦想了吗？」——一个考研统筹与记录工具仓库。

## 仓库结构

```text
future/
├── index.html                 # 考研统筹舱主页(倒计时 / 专注计时 / 进度 / 阶段目标)
├── 考研数学一/
│   └── 函数图像学习/           # 数学函数学习工具
├── 考研英语一/
│   ├── 词根记忆卡片/           # 5258 词单文件记忆工具
│   ├── 知识库/                # DeepSeek 对话整理知识库
│   └── 背单词/                # 艾宾浩斯背单词工具
├── 专业课408/                 # 占位(资料未上传)
└── 考研政治/                  # 占位(资料未上传)
```

## 使用

1. 打开 [考研统筹舱](index.html),在首页看到考研倒计时和四个科目入口。
2. 点击科目卡片进入对应统筹页:
   - 数学一 / 英语一:页面提供原有网页学习工具入口,以及专注计时、进度记录、阶段目标。
   - 政治 / 408:暂无在线工具,使用统筹记录功能。
3. 数据保存在浏览器本地,右上角可导出 / 导入 JSON 备份。
